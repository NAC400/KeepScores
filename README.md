# KeepScores

A mobile-friendly scorekeeper for board games and game nights. Track player scores and keep useful game tools in one screen.

**[Open the app](https://nac400.github.io/KeepScores/)**

## Features

- Add or remove players.
- Add or subtract custom point amounts.
- Sort players by highest score, lowest score, or entry order.
- View total points, average score, and the highest and lowest scores.
- Start, pause, and reset a game timer.
- Pick a random player or roll two six-sided dice.
- Reset scores while keeping players, or reset the whole game.

## Use

1. Open the app and add your players.
2. Enter a point amount beside a player, then tap **Add** or **Sub**.
3. Use the sorting buttons, game statistics, and tools as needed.

Players and scores are saved in your browser on that device. They do not sync across devices, and clearing browser storage removes them. The timer resets when the page reloads.

## Run locally

Download or clone this repository and open `index.html` in a browser. No installation, account, or build step required.

Built with HTML, CSS, and JavaScript in a single file.
